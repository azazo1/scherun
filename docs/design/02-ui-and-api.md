# 界面与接口

## 界面

单页应用, 由 Go 服务同源托管. 主要区域:

- **顶栏**: 应用名, 搜索框, 刷新, 主题切换, 设置, 新建任务.
- **概览条**: 任务总数, 运行中, 已停用, 已挂起.
- **任务列表**: 每行是一张卡片, 包含拖动把手, 状态圆点, 名称与状态徽章,
  触发描述, 程序名, 上次运行时间与退出码, 以及运行/停止/编辑/删除与启用开关.
- **任务编辑抽屉**: 右侧滑入, 分区块编辑基础信息, 触发方式, 启动参数,
  环境变量, 文件重定向与其他选项.
- **文件选择对话框**: 面包屑导航 + 目录列表, 可执行文件带标记.
- **设置对话框**: 后台启动, 日志保留天数, 监听地址.
- **底部状态栏**: 版本号与实时连接状态.

状态更新以 SSE 推送为主, 断线后自动重连. 主题偏好记在 `localStorage`.

## 接口

所有接口只监听回环地址. `/api/*` 需要鉴权, 接受签名 cookie 或 `Authorization: Bearer <启动令牌>`.

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 版本, 提交, 启动时间, 任务数 (无需鉴权) |
| GET | `/api/tasks` | 任务列表, 含运行状态 |
| POST | `/api/tasks` | 新建或更新任务 (带 `id` 则更新) |
| GET | `/api/tasks/{id}` | 单个任务 |
| DELETE | `/api/tasks/{id}` | 删除任务 |
| POST | `/api/tasks/{id}/run` | 手动运行 |
| POST | `/api/tasks/{id}/stop` | 停止进程 |
| POST | `/api/tasks/{id}/enabled` | 启用或停用, 请求体 `{"enabled": true}` |
| POST | `/api/tasks/reorder` | 重排, 请求体 `{"ids": [3, 1, 2]}` |
| GET | `/api/warnings` | 取走运行时告警 (取后清空) |
| GET | `/api/config` | 读取配置 |
| PUT | `/api/config` | 保存配置 |
| GET | `/api/fs/list?path=` | 浏览目录, 供界面选择程序路径 |
| GET | `/api/events` | SSE 事件流, 每秒推送任务快照 |
| POST | `/api/app/focus` | 第二实例请求打开界面 |
| POST | `/api/app/exit` | 优雅退出 |

错误响应统一为 `{"error": "可读信息"}`, 并带合适的 HTTP 状态码:
`400` 参数错误, `401` 未鉴权, `403` 来源不可信, `404` 不存在, `409` 状态冲突.

## 鉴权流程

```
托盘打开 http://127.0.0.1:20008/?token=<启动令牌>
   |
   +-- 服务校验令牌 -> 种下 HttpOnly 签名 cookie -> 303 到 /
   |
   +-- 之后的请求都带 cookie, 服务校验签名, 权威与有效期
```

第二实例走另一条路径: 从 `runtime.json` 读到端口与令牌, 用 Bearer 头调用
`/api/app/focus`, 由主实例打开界面.

`runtime.json` 以 `0600` 权限写入, 正常退出时删除.
