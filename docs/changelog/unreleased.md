# 变更记录

## 未发布

首个可用版本.

- 托盘常驻: 左键打开管理界面, 右键菜单含版本信息与退出, macOS 下隐藏 Dock 图标.
- 本地 Web 界面: 任务列表, 概览统计, 搜索, 拖动排序, 深浅色主题, 实时状态推送.
- 任务管理: 新建, 编辑, 删除, 启用停用, 手动运行与停止.
- 六种触发方式: 手动, 启动时, 保持运行, 定时重复, 定时一次, 直到成功.
- 进程管理: 独立进程组, SIGINT 优雅停止与超时强杀, 标准流重定向, 环境变量与工作目录.
- 失败保护: 连续启动失败自动挂起并记录告警.
- 本地鉴权: 启动令牌换发签名 cookie, Host/Origin 围栏, CSP.
- 单实例: 按数据目录绑定锁, 第二实例转发打开请求.
- 优雅退出: 托盘退出, 界面退出, Ctrl+C 与 SIGTERM 统一收尾.
- 隔离调试: `just debug` 使用独立数据目录与 debug 日志, 可与正式实例并行.
