# scherun v0.1.0

Date: 2026-11-07

首个可用版本: 托盘常驻的后台任务管理器, 管理界面在浏览器里.

## Highlights

- 六种触发方式覆盖手动, 启动, 保持运行, 定时重复, 定时一次与直到成功.
- 任务独占进程组, 停止时先 SIGINT 再兜底强杀, 不留残留子进程.
- 管理界面只监听回环地址, 并用启动令牌, 签名 cookie 与请求围栏三层防护.

## Features

- 托盘常驻: 左键打开管理界面, 右键菜单含应用名与版本, 运行概况与退出入口. macOS 下菜单栏使用模板图标, 随系统明暗自动反色.
- 管理界面: 任务列表, 概览统计, 搜索, 拖动排序, 深浅色主题, 通过 SSE 实时推送状态.
- 任务管理: 新建, 编辑, 删除, 启用停用, 手动运行与停止. 支持从一条命令派生任务字段.
- 触发方式: 手动, 启动时, 保持运行, 定时重复, 定时一次, 直到成功.
- 进程管理: 独立进程组, SIGINT 优雅停止与超时强杀, 标准流重定向到文件, 可配置环境变量与工作目录.
- 失败保护: 短时间内连续启动失败会自动挂起任务, 避免无限重启, 并在界面上给出告警.
- 本地鉴权: 进程级启动令牌换发签名 cookie, 配合 Host 校验与 Origin 围栏, 其他本机程序无法调用接口.
- 单实例: 锁按数据目录绑定, 重复启动时新进程把打开请求转给已有实例后退出; 隔离调试实例可与正式实例并行运行.
- 优雅退出: 托盘退出, 界面退出按钮, Ctrl+C 与 SIGTERM 汇入同一条收尾路径, 依次停止任务, 关闭服务, 刷盘日志.
- 日志: 终端与轮转文件双输出, 按大小与保留天数清理; Windows 安装版无控制台时只写文件.

## Upgrade Notes

1. macOS 上首次打开 dmg 里的应用会被 Gatekeeper 拦下, 因为安装包未签名未公证. 在系统设置的"隐私与安全性"里选择仍要打开即可.

## 分发形态

| 平台 | 产物 |
| --- | --- |
| macOS | `.dmg`, 内含 `scherun.app` 与指向 `/Applications` 的快捷方式 |
| Windows | `-setup.exe` 单文件安装器, 默认安装到用户目录, 不请求提权 |
| Linux | 可执行文件的 `.tar.gz` 归档 |
